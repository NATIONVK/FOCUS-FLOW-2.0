## 🌠 About FOCUS FLOW

FOCUS FLOW is a modern study timer project built around a simple idea:

> **Don't just spend time. Make your time count.**

It aims to combine an immersive timer experience, elegant animations, study tracking, and productivity tools in one application.

Whether you're studying, reading, programming, or working on a personal goal, FOCUS FLOW is designed to help you stay focused.

| Feature | Description |

## 🚀 Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/NATIONVK/FOCUS-FLOW-2.0.git
```

### 2. Open Project

```bash
cd FOCUS-FLOW-2.0
```

### 3. Install Dependencies

```bash
npm install
```

### 4. Start Development Server

```bash
npm run dev
```

### 5. Build Web Application

```bash
npm run build
```

## 📱 Android APK

FOCUS FLOW uses Capacitor for Android integration.

The repository includes a GitHub Actions workflow intended to build a Debug APK.

1. Open the **Actions** tab.
2. Select **FOCUS FLOW Android APK**.
3. Run the workflow.
4. Wait for the build to finish.
5. Download the APK from the successful run's Artifacts section.

*APK availability depends on a successful build.*
